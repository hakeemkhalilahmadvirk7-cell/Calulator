# Calulator

A very small, client-side calculator demo.

Files added:
- index.html — web UI for the calculator
- styles.css — basic styling
- script.js — calculator logic (supports +, -, *, /, percent, ., parentheses, keyboard input)

How to run
1. Open index.html in your browser (double-click or serve with a static server).
2. Use the buttons or your keyboard. Press Enter to evaluate.

Notes
- This is a simple demo intended for learning or as a starting point.
- The evaluator performs a light sanitization. Do not use it with untrusted user input on a server.
